## Описание скриптов и команд

### Задача 1: Вывод отсортированного списка пользователей
**Команда:** `grep -o '^[^:]*' /etc/passwd | sort`
* `grep -o` — ищет совпадения по регулярному выражению и выводит только совпавшую часть (а не всю строку).
* `'^[^:]*'` — регулярное выражение, которое берет всё от начала строки (`^`) до первого символа двоеточия (исключая его). В файле `/etc/passwd` это соответствует именам пользователей.
* `sort` — сортирует полученный список по алфавиту.

### Задача 2: 5 наибольших портов
**Команда:** `awk '$2 > 0 {print $2, $1}' /etc/protocols | sort -nr | head -n 5`
* `awk '$2 > 0 {print $2, $1}'` — обрабатывает файл `/etc/protocols`. Проверяет, что значение во второй колонке больше нуля, и выводит сначала вторую колонку (порт), а затем первую (название протокола).
* `sort -nr` — сортирует данные как числа (`-n`) в обратном порядке по убыванию (`-r`).
* `head -n 5` — оставляет только первые 5 строк результата.

### Задача 3: Программа banner (текст в рамке)
Скрипт принимает строку в качестве аргумента (`$1`) и вычисляет ее длину с помощью `${#text}`. 
* Цикл `for (( i=0; i<length+2; i++ ))` формирует верхнюю и нижнюю границы рамки из символов `-`, подстраиваясь под длину введенного текста.
* `echo` выводит сформированные строки, создавая рамку.

### Задача 4: Идентификаторы C/C++/Java без повторений
Скрипт проверяет наличие переданного аргумента с помощью `if [ -z "$1" ]`.
* `grep -o '[a-zA-Z_]\w*' "$1"` — ищет в файле все слова, соответствующие правилам именования переменных (начинаются с буквы или подчеркивания, далее могут содержать цифры).
* `sort -u` — сортирует найденные идентификаторы и удаляет дубликаты.
* `xargs` — преобразует многострочный вывод в одну строку, разделенную пробелами

### Задача 5: Регистрация пользовательской команды
Скрипт проверяет, существует ли переданный файл (`-f "$1"`).
* `chmod +x "$1"` — выдает файлу права на исполнение.
* `sudo cp "$1" /usr/local/bin/` — копирует скрипт в системную директорию `/usr/local/bin/`, которая находится в переменной PATH

### Задача 6: Проверка наличия комментариев в начале файлов
Скрипт перебирает файлы с расширениями `.c`, `.js`, `.py` в папке `files/`.
* `head -n 1 "$file"` — берет только первую строку каждого файла.
* `grep -qE '^(//|/\*|#)'` — тихо (`-q`) ищет начало комментария по регулярному выражению (`-E`). Ищет строки, начинающиеся с `//`, `/*` или `#`.
* `&& echo ... || echo ...` — логическая конструкция: если команда `grep` нашла совпадение (вернула 0), выполняется первая команда `echo`, иначе вторая.

### Задача 7: Поиск файлов-дубликатов
**Команда:** `find "$1" -type f -exec md5sum {} + | sort | uniq -w32 -D`
* `find "$1" -type f` — ищет все обычные файлы (`-type f`) в указанной директории.
* `-exec md5sum {} +` — вычисляет MD5-хэш для каждого найденного файла.
* `sort` — группирует одинаковые хэши вместе.
* `uniq -w32 -D` — оставляет и выводит только те строки, у которых совпадают первые 32 символа (`-w32`, длина MD5-хэша), выводя все дубликаты (`-D`).

### Задача 8: Архивация по расширению
**Команда:** `find . -name "*.$1" | xargs tar -cvf "$2"`
* `find . -name "*.$1"` — ищет в текущей папке все файлы с расширением, переданным в первом аргументе (`$1`).
* `xargs tar -cvf "$2"` — передает найденные пути утилите `tar`, которая создает (`-c`) архив с именем из второго аргумента (`$2`), выводя процесс на экран (`-v`).

### Задача 9: Замена 4 пробелов на табуляцию
**Команда:** `sed 's/    /\t/g' "$1" > "$2"`
* `sed` — потоковый текстовый редактор.
* `'s/    /\t/g'` — команда замены (substitute). Ищет ровно 4 пробела и заменяет их на символ табуляции (`\t`). Флаг `g` (global) означает, что замена будет произведена для всех совпадений в строке, а не только для первого. Результат перенаправляется (`>`) в новый файл (`$2`).

### Задача 10: Поиск пустых файлов
**Команда:** `find "$1" -type f -empty`
* `find` ищет внутри переданной директории (`$1`).
* `-type f` — ограничивает поиск только файлами.
* `-empty` — фильтрует результаты, оставляя только файлы с нулевым размером (пустые).
